# GRCR-003：独立模型 A/B 盲评基准

2026-10-30。**当前状态：基准工具已离线生成并通过 Python 语法检查；独立文本模型未运行，因而没有 A/B 胜率。**

## 测试对象
同一模型同一选项下分别运行三个任务，每题两组：
- A：只给自然语言目标，要求实施方案和验证。
- B：同任务加 GRCR 逆向条件发现、目标必需/方案条件区分、已有能力查证、成熟方案检索和停止条件。

三个案例：
1. 狭窄管道怪物追逐；
2. 已存在建筑构件/空间拓扑基础上的门功能；
3. 白天经营、夜晚搜刮撤离的资源选择。

## 评审
每题预设五项候选重要条件，各0/1/2分（未提及/笼统提及/可操作）；明确把伪必要方案当成必须条件则扣2分，例如“NavMesh是唯一方法”、“不检查已有系统就新建空间图”、“做平滑数值便能保证有趣”。同时记录搜索与Token成本、冗余探索、验收可行性、证据真实性。

流程：独立生成六份回答 → 放入 submissions → 用固定种子随机匿名化 → 评审冻结 → 通过隐藏映射揭盲。评审不应提前向受测模型泄露 rubric。

## 可复现工具
配套可运行的 Python 标准库实现含三个文件 `benchmark.py`、`cases.json`、`README.md`。使用：
```sh

```
